1. Project Overview & Architecture

This project is an exact implementation of Lab Exam 1 – Stateless Widget. The primary goal is to replicate the official Campus Store mobile checkout screen with 100% adherence to the design specifications, nested component hierarchy, reusable component design, button callbacks, and strict reliance on StatelessWidget without third-party UI dependencies.

Key Technical Highlights

  • Pure StatelessWidget Architecture: Both ShoppingCartPage and the reusable CartItemCard are strictly implemented as StatelessWidgets. State is immutable as required by the examination guidelines.
  • Reusable Component Design: CartItemCard accepts productName, price, quantity, and icon via its constructor, used for all three products with zero code duplication.
  • Responsive & Overflow-Free Layout: Wrapped in a vertical SingleChildScrollView with carefully balanced margins and paddings, ensuring flawless rendering across any mobile screen size.
  • Exact Console Output Callbacks: Every button (Back arrow, Shopping bag, Change, Plus, Minus, Delete, and Place Order) prints the exact required output string via debugPrint().
  • Design System Fidelity: Precise implementation of colors (#1D4ED8 primary blue, #0F172A dark text, #F4F6FB background), 16px card radius, 1px border (#E2E8F0), and custom icon tiles.
